# أومني — حزمة التركيب الكاملة

هذا المستودع يحتوي على تفكيك حزمة تركيب أومني إلى ملفات منفصلة قابلة للرفع مباشرة إلى السيرفر.

## هيكل المشروع

```text
.
├── README.md
├── .env.example
├── database/
│   └── omni.sql
├── public_html/
│   ├── .htaccess
│   ├── api.php
│   ├── setup.php
│   ├── index.html
│   └── js/
│       ├── aman-core.js
│       ├── aman-views.js
│       ├── aman-admin.js
│       ├── aman-chat.js
│       └── aman-reviews.js
└──
```

## الخطوات السريعة

1. أنشئ قاعدة البيانات في MySQL.
2. نفّذ ملف `database/omni.sql` في phpMyAdmin.
3. انسخ ملف `.env.example` إلى `.env` واضبط القيم الصحيحة.
4. ارفع محتويات `public_html/` إلى مجلد الموقع.
5. استخدم `setup.php` لإنشاء حساب المدير المؤقت ثم احذفه بعد الاستخدام.
6. افتح `index.html` في المتصفح.

## ملاحظات السلامة

- لا تترك `setup.php` على الخادم بعد الانتهاء.
- احتفظ بملف `.env` خارج مجلد الموقع.
- أزل أي ملفات مؤقتة بعد التثبيت النهائي.

## التهيئة السريعة

```bash
cp .env.example .env
# ثم عدّل القيم في الملف
```

## ملاحظة

هذه الحزمة مبنية على تصميم عملي قابل للتوسعة، وهي مناسبة للبدء السريع في فرضية متجر/موقع مدفوعات + متجر إلكتروني + شات + تقييمات + عجلة هدايا.
